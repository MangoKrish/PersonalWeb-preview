About

Build the whole thing.Then make it respect its user.

I'm a Computer Science co-op student at McMaster University who likes building the whole thing — the model, the backend, the interface, and the deploy script. Most of what I make starts with a real person's problem: a freelancer rewriting the same proposal for the tenth time, a student memorizing ninety-four physics formulae, two people planning life across a ten-and-a-half-hour timezone gap.

That's why my projects keep turning out local-first, bring-your-own-key, and dependency-free — a voice assistant that never sends audio to a cloud, an extension whose API key never leaves your device, a matching engine that explains its recommendations in plain language instead of exposing raw scores.

Right now I'm exploring software engineering, robotics, and natural-language processing — and looking for a co-op team that ships.

      Peppa — Local voice assistant

      A Jarvis-style voice assistant that runs entirely on a laptop — no cloud, no API keys, no audio leaving the room.

      Sub-2-second voice-to-voice latency, 46 tool skills, and a deterministic reflex layer that keeps it answering even with the LLM runtime fully offline.

      • 16,400+ lines

      Local-only build

      Ask for a demo

      Case fileproblem, approach, stack, outcome
      Problem
      Voice assistants ship your voice, questions, and files to someone else's servers. I wanted Jarvis-grade help with nothing leaving the machine.
      Approach
      Five on-device models (14B chat, 32B reasoning, coder, vision, embeddings) behind a router with five thinking modes — the deepest one plans, investigates with tools, then has a second model red-team the draft before it's spoken. Speech streams sentence-by-sentence while the answer is still generating, with barge-in interruption. For arithmetic it refuses to guess in-weights and instead writes and runs Python in a sandbox.
      Stack
      Python 3.12 · Ollama (Qwen2.5) · MLX-Whisper · on-device TTS voice cloning · PySide6 · local RAG · sandboxed code execution
      Outcome
      Sub-2-second voice-to-voice latency, 46 tool skills, and a deterministic reflex layer that keeps it answering even with the LLM runtime fully offline.

      Dimension Dash — Physics as a game

      A spaced-repetition study game that teaches all 94 dimensional formulae from Class 11 physics.

      Vanilla JS / Web Audio · 20260 deps

      • 94 formulae
      • 6 game modes
      Private build
      Case fileproblem, approach, stack, outcome
      Problem
      Dimensional formulae are a classic exam trap — 94 near-identical expressions that students usually brute-force by rote.
      Approach
      A custom SM-2/Leitner spaced-repetition scheduler drives six exam-aligned game modes — including a Build Lab where formulae are assembled from exponent bricks. Confusion sets are computed at runtime by grouping quantities with identical dimensions, and anchor formulae are force-surfaced first so the rest can be derived, not memorized.
      Stack
      Vanilla JS/HTML/CSS · Web Audio synthesis · versioned localStorage · zero dependencies
      Outcome
      ~3,000 dependency-free lines with a 94-cell mastery heatmap, JSON export/import, pre-paint theming, and reduced-motion support.
