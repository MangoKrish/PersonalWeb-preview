01 · 2026 · Python / MLX / Ollama

Peppa

A Jarvis-style voice assistant that runs entirely on a laptop — no cloud, no API keys, no audio leaving the room.

The problem
Voice assistants ship your voice, questions, and files to someone else's servers. I wanted Jarvis-grade help with nothing leaving the machine.
What I built
Five on-device models (14B chat, 32B reasoning, coder, vision, embeddings) behind a router with five thinking modes — the deepest one plans, investigates with tools, then has a second model red-team the draft before it's spoken. Speech streams sentence-by-sentence while the answer is still generating, with barge-in interruption. For arithmetic it refuses to guess in-weights and instead writes and runs Python in a sandbox.
Outcome
Sub-2-second voice-to-voice latency, 46 tool skills, and a deterministic reflex layer that keeps it answering even with the LLM runtime fully offline.

03 · Jun–Jul 2026 · React / Supabase / SQL

MentorMatch

A mentor-recommendation engine that lives inside Postgres and gives students reasons, never raw scores.

The problem
Students on a mentorship platform picked mentors from a flat directory; naive match scores are either opaque or uncomfortable to show.
What I built
A weighted compatibility engine as a security-definer plpgsql RPC — normalized 0–100 scoring across admin-tunable dimensions with cached score rows. Privacy by design: no student can read the scores table; the API returns only ranked mentors with plain-language reasons. Then a zero-behavior-change modular refactor of the production portal, verified against the pre-refactor codebase, and a WCAG-AA design-token redesign.
Outcome
644 lines of SQL across 4 migrations; a 92-file refactor (+6,599 / −3,029 lines) with byte-level behavior parity. My end of a two-person product team.

ProposalPilot

A Chrome side-panel extension that turns any job post into a tailored freelance proposal — on your own API key.

The problem
Freelancers rewrite near-identical proposals all day, and most AI helpers route their clients' job posts through a third-party server.

Bring-your-own-key architecture: the browser talks directly to OpenAI, Anthropic, or Gemini — no backend at all. 05 · 2026 · Vanilla JS / Node stdlib

Duet

A collaborative planner for two people in timezones 10.5 hours apart — built from scratch with zero packages.

The problem
Shared calendars assume the same timezone, need accounts in someone's cloud, and fall over offline.
What I built
A last-write-wins merge-by-id sync algorithm implemented identically on client and server, so devices can edit offline and reconcile deterministically on reconnect. Live sync over Server-Sent Events; per-user timezone math with the Intl API, including day-boundary handling; a mutual free-time finder that intersects both schedules; and an optional AI assistant served by a local LLM.

~6,000 hand-written lines, zero npm packages, five calendar views, atomic write-then-rename persistence.

06 · 2026 · Vanilla JS / Web Audio

Dimension Dash

A spaced-repetition study game that teaches all 94 dimensional formulae from Class 11 physics.

The problem
Dimensional formulae are a classic exam trap — 94 near-identical expressions that students usually brute-force by rote.
What I built
A custom SM-2/Leitner spaced-repetition scheduler drives six exam-aligned game modes — including a Build Lab where formulae are assembled from exponent bricks. Confusion sets are computed at runtime by grouping quantities with identical dimensions, and anchor formulae are force-surfaced first so the rest can be derived, not memorized.
Outcome
~3,000 dependency-free lines with a 94-cell mastery heatmap, JSON export/import, pre-paint theming, and reduced-motion support.
